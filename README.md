# MachiTalk v1.7.0

街で使う英会話を練習する、Android Chrome向けの無料・端末内保存型PWA。ASK 4シーン、GUIDE 4シーン。ログイン、広告、外部AI API、アクセス解析はありません。

## 開発・公開

静的ファイルをHTTPSで公開します。ローカルでは `python3 -m http.server 8000` をこのディレクトリで実行し、`http://localhost:8000/` を開きます。`npm test` で教材の整合性と判定例を確認できます。GitHub Pagesは `main` ブランチのルートを公開元とします。

Web Speech APIの読み上げ音声・認識精度・権限挙動はブラウザと端末に依存します。Chromeの音声認識はブラウザ提供サービスを使う場合があり、アプリ自身は音声や学習履歴を送信しません。認識不可の場合も文字入力、回答例、スキップで進めます。採点は登録した意図・表現のルールによる目安で、発音の評価ではありません。v1.2では認識途中の文字と最大5候補を使い、対応ブラウザには会話の語句を弱い補助情報として渡します。認識の曖昧な失敗には最大3回の再試行を設け、はっきりした誤答には例文をすぐ表示します。

会話中の「ヒントモード」は設定に保存され、各問題の英語の言い出しと単語を表示します。「答えを見る」で例文全文と音声を確認できます。会話中のアバターはゆっくり揺れ、聞き取り中は少し大きく動きます。端末の「動きを減らす」設定では動かしません。正解時の写真上の演出と効果音は段階ごとに変わります。意味の言い換えは教材に登録した表現を中心に判定し、自由な英作文をすべて理解するAI判定ではありません。

練習方法は「自由に答える」「聞いて答える」「2秒で見て覚える」の3種類から設定画面で会話の前に選び、全問題に適用します。後の2モードでは質問の音声が終わって少し間を置き、例文を音声または2秒間の表示で示した後、記憶を頼りに答えます。もう一度お手本を再生できます。どのモードでも例文と違う自然な言い方は同じ判定ルールで採点します。音声が使えない場合は2秒の表示に切り替えます。会話中の選択欄を省き、アバター写真を画面の大部分に表示します。

録音ボタンは日本語の返答指示の右に表示します。音声認識が利用できる端末では、最初の録音をアバターの質問（記憶モードでは見本の音声または2秒表示）の後、850ミリ秒待って自動開始します。録音中は小さな赤い点と表示で知らせます。聞き取りエラーなどで再挑戦する場合はボタンから手動で録音します。端末が音声認識に対応しない場合、読み上げが失敗した場合は手動操作・文字入力を利用できます。見本の朗読には名前から男性と分かる端末の英語音声を優先し、見つからない場合は端末音声のピッチを低めに設定します。Web Speech APIに声の性別を直接指定する機能はありません。

認識途中の英語と確定した聞き取り結果は、アバター写真の下端の半透明な表示で確認できます。聞き取りが途中で止まった場合も、その時点までに認識された英語を同じ位置に残します。文字入力した場合も入力内容をここに表示します。

## シーンを追加

1. `data/scenes/` に既存シーンを参考に新しいJSONを作成します。`sceneId`、`startNode`、各ノードの`prompt`、`task`、`instruction`、`hint`（`words` と `starter`）、`acceptedIntents`、`examples`、`next`を設定します。
2. `data/scene-registry.json` の `scenes` に `id`、表示情報、`file` を追加します。
3. `npm test` を実行します。エンジンの変更は不要です。

各 `acceptedIntents` の `expressions` は単語またはフレーズで、同一intent内はOR、`required: true` のintent間はANDです。汎用意味理解ではないため、教材ごとに言い換えを追加できます。`next` は次ノードIDまたは `{ "default": "n2", "variants": [{ "ifIntent": "choice", "node": "n2b" }] }` として分岐できます。

## アバターを追加

`data/avatar-registry.json` の `avatars` に画像と各表情を登録すると選択できます。各表情に個別画像の `image` を指定でき、既存のスプライト形式では `crop` と位置も利用できます。会話データの `avatar` にIDを指定できます。初期Aikoは承認済みのMachiTalk画像を参照した4枚の既存画像（512×768）と、質問・励まし・正解時に使う4枚の追加画像（1024×1536）を使用します。人物画像はこのリポジトリ用の素材として扱ってください。

設定の「会話のアバター」でAikoとLinneaを写真を見ながら切り替えられます。選択した相手は次の会話とホーム画面に反映され、端末に保存されます。Linneaは選んだ北欧風の金髪女性候補を基に、話す・聞く・励ます・正解4段階の表情を揃えた1024×1536のWebP画像8枚を使用します。初期選択のAikoは維持します。

学習履歴と設定はIndexedDBに保存し、将来の移行用に`schemaVersion`を付与します。ページをオフラインで起動するには一度オンラインで表示します。個々のシーンJSONは利用時に読み込みキャッシュするため、未訪問シーンはオフラインでは使えない場合があります。
